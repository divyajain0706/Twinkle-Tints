# 🌸 Twinkle Tints – Beauty & Cosmetics Website

Twinkle Tints is a modern beauty and cosmetics e-commerce website built to provide users with a smooth and elegant online shopping experience for makeup and skincare products.

## 📌 Website Purpose
The website allows users to browse, select, and purchase beauty products through a clean, user-friendly interface with secure authentication and payment features.

## ✨ Features & Functionalities
- User registration and login system  
- Categorized product listings (Makeup, Skincare, Accessories)  
- Product browsing with details  
- Shopping cart management (add, update, remove items)  
- Secure checkout and payment functionality  
- Well-structured website sections (Home, Products, About, Contact)  
- Integrated AI chatbot for user guidance and assistance  
- Responsive UI with a soft pink aesthetic  

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** XAMPP / Apache  
- **Version Control:** Git & GitHub  
- **AI Integration:** Gemini / OpenAI API
